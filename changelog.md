# Anno 1800 Island ReSkinner by gz2k2

# Changelog

## [v0.97.24]

### Added
- Added Clay Slot, Oil Slot, Gas Slot, and River Slot options to the "Slot Map".
- Placed slots can now be moved using the "Move" function and deleted as needed.
- Added status popups to various functions for improved UI feedback.

### Changed
- Added object categories including region filters (Old World, New World, Arctic, Enbesa).
- Improved selection functionality and right-click context menus in both Slot Map and Object Map.
- Optimized zoom and pan controls.

### Fixed
- Performance updates and optimizations.

### Known Issues
- Object movement in the Object Map is currently not working properly.
